# ChatSpin demo — target 2 minutes 45 seconds

Before recording: configure the real Twitch connection, run the live AI evaluation, open a channel chat with consenting test viewers, prepare the viewer space, and add the OBS Browser Source. Use real activity for the Twitch footage. Clearly label any separate simulated-data footage. Record development snippets while building and save the actual Codex session ID.

## Script

**0:00–0:20 — The problem**
“On a busy Twitch stream, good questions get buried. ChatSpin turns that busy chat into a conversation, while making room for questions from just one person.” Show the connected channel and dashboard together.

**0:20–0:55 — From chat to a question**
Two viewers post equivalent `!ask` questions. Show originals, unique support, and the representative question. Show a different question on the same topic staying separate. Explain that the AI organizes questions and never invents answers. If an AI match needs review, show the review instead of pretending it was automatic.

**0:55–1:25 — A fair turn**
Choose Equal chances and spin. Show the dashboard and OBS selecting the same question. Show the exact-chance list and explain By support. Spotlight a single-support question to demonstrate that minority questions stay eligible. Mark it answered live.

**1:25–1:45 — People, too**
Viewers enter with `!join`. Switch to Participant Wheel, close registration, and spin. Explain one entry per stable Twitch ID, optional repeat exclusion, and no automatic microphone access.

**1:45–2:10 — Answers that stay useful**
Save an approved written answer. Submit an exact equivalent from a viewer, then show that answer in that viewer's space. Explain that uncertain semantic matches require review and nothing is posted automatically to general chat.

**2:10–2:35 — Built with Codex**
Cut to genuine development footage. “I built ChatSpin with Codex from an empty repository: the TypeScript server, React dashboard, Twitch EventSub integration, synchronized wheel, and tests for unique support, corrections, permissions, and selection.” Show a passing test run and a correction in the UI.

**2:35–2:45 — Close**
“Every voice deserves a turn. ChatSpin makes it easier to listen.” End on the OBS presentation.
